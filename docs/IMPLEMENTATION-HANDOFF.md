# Handoff implementasi lokal

14 Oktober 2026. Aturan bisnis PRD v0.3 tetap berlaku. Sistem inti sudah dibangun; status ini tidak menyatakan kesiapan produksi atau sambungan eksternal sudah teruji.

## Yang tersedia

- Landing customer, checkout QRIS, konfirmasi/status dan halaman voucher tanpa akun.
- Satu panel operator bernama: Ringkasan, Pesanan & Voucher (Livewire), Pengaturan. Upload QRIS/cabang/aturan, approval/koreksi, klaim, transfer sekali, pengiriman manual WhatsApp dan ekspor privat.
- Snapshot gambar merchant/harga/policy. Referensi penerimaan unik per merchant; paid_at actual WIB berbeda dari verified_at. Approval, voucher, audit dan job disimpan satu transaksi.
- Row lock, unique constraint dan idempotency klaim. Quote usia/revision dicek kembali. Klaim mengunci potongan untuk input manual ke sistem order; tidak ada integrasi order atau ledger DP.
- Token acak 256 bit, hash lookup dan penyimpanan terenkripsi; transfer mencabut token/kode lama. Halaman bearer private/no-store/noindex/no-referrer. QR voucher memakai BaconQrCode dengan quiet zone empat modul, gambar QRIS merchant tidak digenerate/diubah.
- Pixel hanya pada landing dengan consent; InitiateCheckout dikirim ketika customer mengirim form checkout. Pixel tidak dimuat pada halaman pesanan/voucher bertoken. CAPI Purchase memakai data checkout dan paid_at aktual, VoucherRedeemed terpisah; event ID stabil untuk retry.
- Pengiriman Meta/WACO melalui database queue. Adapter WACO berdasarkan kontrak resmi menerima template tiga variabel body dan sender eksplisit; credentials/URL HTTPS wajib. Status WA PENDING/SENDING/SENT/FAILED/SKIPPED/UNCERTAIN, dengan retry otomatis terbatas pada429. Marker sebelum I/O mencegah retry buta sesudah crash/timeout; revision/token pemilik diperiksa dengan row lock. Kirim ulang admin memerlukan konfirmasi riwayat/request key dan tidak menerbitkan voucher baru. Konfigurasi belum tersedia pada lingkungan lokal, sehingga tombol otomatis disabled dan job SKIPPED; manual membuka WhatsApp dengan link pemilik aktif.
- Ekspor CSV background, formula injection dinetralkan, unduh hanya peminta, umur file 24 jam. Anonimisasi 90 hari sesudah digunakan/kedaluwarsa atau pesanan unpaid tidak aktif; kasus bantuan terbuka dikecualikan. Angka/reference ledger dipertahankan.
- Docker Compose: app, worker, scheduler dan PostgreSQL; volume persisten, DB tanpa port publik. Database test dan fixture UI dipisahkan. Log akses Apache tidak mencatat URL/token/identitas.

## Bukti yang telah diperiksa

Akses guest/nonaktif pada retry/resend dan route binding turut dicek; ActiveAdmin kini dijalankan sebelum SubstituteBindings pada semua route admin. Pengguna memilih tidak menambahkan pengujian HTTP tiruan WACO; perilaku provider/pengiriman belum divalidasi melalui test adapter ataupun akun nyata.

## Enhancement interaksi dan lifecycle

Seluruh usulan enhancement disetujui pengguna. Dialog konfirmasi bersama dipakai untuk verifikasi uang masuk, klaim, transfer sekali, versi aturan baru, dan penonaktifan operator; ringkasan menggunakan input yang akan dikirim, fokus awal Batal, Escape membatalkan. Tidak ada perubahan syarat, harga, tier atau hak akses. Toast digunakan untuk salin kode/link dan simpan data ringan; kegagalan dan hasil transaksi tetap persisten. Validasi bahasa Indonesia menghubungkan kesalahan ke input, membuka bagian terkait dan memfokuskan isian pertama. Tombol form menampilkan proses dan mencegah submit ganda pada halaman yang sama; perlindungan transaksi server tetap diperlukan.

Status customer diperbarui dengan GET **Periksa status terbaru**, sesuai verifikasi pembayaran manual. Link pesanan dapat disalin, bantuan tersedia saat menunggu, dan instruksi melarang pembayaran ulang. Halaman voucher menunjukkan tanggal/nilai tier berikutnya dari snapshot tanggal pembayaran aktual WIB; riwayat terpakai tidak menyuruh scan QR yang sudah tidak aktif. Bagian pengaturan disimpan melalui fragment URL, filter daftar dapat direset, dan hasil daftar yang gagal dimuat dinonaktifkan sampai refresh berhasil. Retry daftar hanya membaca ulang; tidak mengulang ekspor atau POST keuangan. Kamera memiliki feedback pembukaan dan fallback manual.

Tiga test HTTP baru memperiksa validasi checkout dalam bahasa Indonesia, tanggal tier berikutnya pada batas kalender WIB, dan pemulihan HTTP419 melalui URL status kanonis dengan header privat serta tanpa redirect arbitrer. Suite terakhir: **22 test / 202 assertion**, PHP8.4.26 dan PostgreSQL17.11. Pengujian tetap pada pembayaran, klaim dan hak akses; tidak ditambah test provider WACO.

Browser enhancement: **131 pemeriksaan viewport, 34 state**, nol document overflow dan nol pageerror pada report. Lebar utama 320/390/768/1024/1440/1920; state interaksi tambahan memiliki bukti 390/1440, dialog pembayaran/klaim juga seluruh enam lebar. Alur checkout → konfirmasi → approval → klaim berhasil. Pembatalan dialog, fokus Batal/keyboard dialog, validasi input pertama, gagal/berhasil salin, kegagalan request Livewire → recovery → reset filter, serta kamera pending/ditolak turut diperiksa. Semua 34 galeri dibuka saat inspeksi visual; screenshot/report di `.impeccable/review/enhancement/`, harness `scripts/inspect-ui.mjs`.

HTTP419 diperoleh dari request nyata tanpa token dengan Sec-Fetch-Site cross-site, lalu respons tersebut dirender dalam browser untuk meninjau UI dan tautan pemulihannya. Ini bukan simulasi end-to-end expiry sesi browser: Laravel13 dapat menerima request dengan origin yang valid. Clipboard dan kamera memakai simulasi kemampuan/izin; tidak membuktikan perangkat fisik. Dialog policy/operator/transfer diuji sampai pembatalan, bukan perubahan nyata pada QA. Bukti nonempty tetap sintetis dan QRIS tidak dapat dibayar; QA tanpa worker, tanpa kiriman WA/Meta nyata.

Detector enhancement dijalankan **sekali terhadap resources/views**, exit0 dengan laporan lengkap `[]` di `.local/enhancement-detector.json`. Itu tidak menyatakan CSS/JS sudah discan atau aksesibilitas lengkap sudah diaudit. Arsip critique historis ditandai closed otomatis oleh helper setelah target berubah; status itu bukan bukti seluruh temuan terselesaikan.

Fresh finish review enhancement memberi **disposition: ship** pada bukti UI lokal dan sampel implementasi. Reviewer memvalidasi 167 PNG (131 capture + desktop/mobile + 34 galeri), membuka seluruh galeri dan 21 original. CSS/JS diperiksa langsung karena detector hanya mencakup view. Lifecycle kedaluwarsa dan pemulihan BFCache diperiksa dari source, tanpa capture/jalankan khusus; seluruh cabang validasi server/pemetaan error pengaturan belum dicoba satu per satu. Verdict ini tidak mencakup sertifikasi produksi, layanan eksternal atau audit aksesibilitas penuh.

DESIGN.md v0.6 dan sidecar schema2 diselaraskan dengan komponen/perilaku final; palet, identitas, tipografi dan layout disetujui tetap dipertahankan. ## Batas dan kebutuhan nyata

1. QRIS merchant asli, nama/ID penerima, data cabang dan nomor bantuan belum dimasukkan pada database utama. Checkout pembayaran tetap dinonaktifkan sampai QRIS tersedia. Uji nominal, merchant dan penggunaan berulang di aplikasi pembayaran/perangkat nyata belum dilakukan.
2. Meta Pixel/Dataset/access token belum tersedia. Payload/versi bersumber dari dokumentasi resmi; **penerimaan Test Events, kualitas matching dan atribusi iklan belum divalidasi**. Jangan menyatakan seluruh pembayaran dapat diatribusikan. Adapter WA sudah diimplementasikan berdasarkan [dokumentasi WACO](research/WACO-API.md), namun API key/sender/template APPROVED KGJ belum tersedia. Kontrak provider tidak menjamin idempotency outgoing; timeout/hasil tak pasti memerlukan pemeriksaan operator. Webhook delivered/read tidak diimplementasikan. Belum ada pengujian HTTP tiruan WACO, sesuai batas yang dipilih pengguna, maupun kiriman nyata.
3. Belum ada audit aksesibilitas lengkap/keyboard 200% zoom, test kamera fisik/lintas Safari/Firefox, load test besar, atau simulasi restore bencana. Kamera memakai BarcodeDetector jika didukung, selalu ada input manual. CSV authorization diverifikasi; hasil besar/timeout dan retry eksternal nyata belum diuji.
4. Domain/hosting/HTTPS tetap pengguna. Environment produksi, trusted proxy dan cookie secure mengikuti lokasi deployment; token/IP tidak boleh masuk log ingress/CDN. Cadangkan database, storage dan APP_KEY bersama; kehilangan APP_KEY membuat field terenkripsi tidak terbaca. Akun lokal pengujian harus dinonaktifkan sebelum rilis.

Panduan menjalankan, setup operator dan konfigurasi WACO: [README](../README.md). Pengiriman otomatis lokal tetap dinonaktifkan sampai credentials, sender, template APPROVED dan alamat HTTPS tersedia; pengiriman manual menjadi pilihan yang terlihat jelas.
